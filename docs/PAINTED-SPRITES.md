# Painted bestiary sprites

Eight full-body, single-pose sprites based on `docs/BESTIARY-ART.md`, generated with built-in ImageGen using Animal Factory Tactics `art/character-review.jpg` as a style-only reference. The user's painted-sprite direction supersedes the engraving direction for this separate set.

Files are in `img/sprites/enemy/`. Existing combat portraits remain in `img/enemy/`. These are static sprite assets, not animation cycles or an activated combat portrait replacement. Open `img/sprites/index.html` to inspect them on light, dark, and checker backgrounds. The normal build copies this gallery and its assets into dist.

## Exact prompts

Each generation used this shared prefix followed by its subject below:

Use case: stylized-concept. Create ONE isolated full-body 2D game sprite for Sewer Demons. Reference image is STYLE ONLY: match Animal Factory Tactics hand-painted sculptural shapes, economical dark olive contours, textured brushwork, muted earthy colors, warm ochre highlights, convincing anatomy and readable compact silhouette. Horror, not cute. No engraving, no pixel art, no 3D render. Elevated three-quarter view looking down about 30 degrees, facing screen-right. Single idle/readied pose, entire body and extremities visible, centered with generous padding in a square canvas. Genuinely transparent alpha background, no scenery, ground, shadow, text, labels, grid or watermark. Do not copy outfits or animal species from reference. Subject:
